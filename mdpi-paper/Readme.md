# MDPI Paper

This directory contains the MDPI paper derived from this research, together
with the supporting material used to reproduce the figures presented in the
manuscript.

## Contents

### `mdpi-paper.pdf`

The full version of the MDPI paper.

### `figure-reproduction/`

Contains the Python scripts and supporting experimental data used to reproduce
the figures presented in the paper.

See [`figure-reproduction/README.md`](figure-reproduction/README.md) for
details on the required files, dependencies, figure-generation procedure, and
scope of reproducibility.
